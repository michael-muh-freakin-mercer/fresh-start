# Omarchy customization rules

I am customizing my personal Omarchy desktop.

Rules:

- Assume I am a beginner.
- Prefer small, reversible changes.
- Never edit files under /usr/share/omarchy.
- You may inspect /usr/share/omarchy for reference.
- Prefer user overrides under ~/.config.
- Preserve Omarchy's existing architecture and theme system.
- Do not replace working Omarchy components unless I explicitly ask.
- Do not install packages unless necessary.
- Before installing a package, explain why it is needed.
- After every task:
  - validate edited config files where possible
  - show me the git diff
  - explain how to reload the affected component
- Do not make unrelated changes.
